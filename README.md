# Adovan — Personal CV Website

Personal CV website built with HTML, CSS, and vanilla JavaScript.
Inspired by [minhpham.design](https://minhpham.design).

## Features

- Custom cursor
- Loading screen with counter
- Light / Dark mode toggle (auto-detect + localStorage)
- Scroll progress bar
- Marquee animation
- Scroll reveal (IntersectionObserver)
- 3D tilt on profile photo
- Testimonial slider
- Responsive layout

## Local Preview

Open `index.html` in your browser.

## Deploy to GitHub Pages

1. Create a new GitHub repository (e.g., `cv-adovan`)
2. Upload all files in this folder
3. Go to **Settings → Pages**
4. Under **Source**, select **Deploy from a branch**
5. Choose branch `main` and folder `/ (root)`
6. Click **Save**
7. Wait 1–2 minutes, your site is live at `https://<username>.github.io/cv-adovan/`

## File Structure

- `index.html` — main page
- `style.css` — all styles
- `script.js` — all interactions
- `foto-profil.jpg` — profile photo
- `CV-Adovan.pdf` — downloadable CV (optional)
- `.nojekyll` — required for GitHub Pages
